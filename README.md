# Green Future Collective

A modern web platform developed for **Green Future Collective**, an environmental and community-focused NGO.

The website provides a central platform for presenting the organisation's projects, impact, initiatives, team, news, volunteering opportunities, fellowship programmes, and ways for supporters to get involved.

## Features

- Responsive multi-page website
- Projects and initiatives showcase
- Impact and community metrics
- News and updates section
- Photo gallery
- Team and organisation information
- Volunteer and fellowship pages
- Collaboration opportunities
- Donation and contact pages
- Reusable UI component system
- Interactive carousels, marquees and animated content
- Responsive navigation and layouts

## Tech Stack

- React 19
- TypeScript
- TanStack Start
- TanStack Router
- TanStack Query
- Vite
- Tailwind CSS
- Radix UI
- Recharts
- React Hook Form
- Zod
- Lucide React

## Running Locally

```bash
git clone https://github.com/Arpitmeh-glitch/cultivate-circular-stories.git
cd cultivate-circular-stories
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
